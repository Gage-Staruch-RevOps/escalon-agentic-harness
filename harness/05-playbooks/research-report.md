# Research report

1. Frame the question and the decision it serves. Pick a sensible scope rather than asking.
2. `deep-research` for multi-source work; `competitive-brief` for competitors.
3. Every claim gets a source link; prices and dates get checked against the vendor's own page.
4. Synthesize: `synthesize-research` (themes, ranked findings, recommendation).
5. Deliver in the team's doc tool when it's for sharing; plain chat when it's for the user alone. No company data goes into outside tools to do the research.

## Done means

A recommendation up top, sourced findings, open questions named.
