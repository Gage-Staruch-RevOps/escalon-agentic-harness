# 10-company: company-wide skills

Skills every team uses. Start with these placeholders (each becomes a folder with a `SKILL.md`, copied from `90-templates/SKILL.template.md`), then add a row for each in `00-router/skill-router/references/registry.md`:

| Placeholder | Layer | What it holds |
| --- | --- | --- |
| `company-definitions` | L1 | What business numbers and terms mean (pipeline, bookings, revenue, churn, ...), and which system is the source of truth for each. |
| `company-brand` | L5 | Colors, fonts, logos, voice and the no-em-dash rule, for anything branded. |
| `<system>-data-access` | L2 | One per system of record (CRM, finance, warehouse): how to query it reliably, limits, gotchas. |
| `company-policies` | L1 | Approved tools, data handling, what needs a manager's yes. |
