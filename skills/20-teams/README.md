# 20-teams: one folder per team

Each team owns its own folder and its own rows in `00-router/skill-router/references/registry.md` (section 5). Create the folder when the team adds its first skill:

```
20-teams/
  sales/
  marketing/
  finance/
  operations/
  revops/
  client-success/
  engineering/
```

A good first skill for any team is its most repeated deliverable (a weekly report, a request desk, a handoff checklist). Chains for team skills are numbered C50 and up in `chains.md`.
